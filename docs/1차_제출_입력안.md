# RePlan 1차 심사 제출 입력안

## 서비스 정보

- 서비스명: 실시간 여행 재설계 가이드 RePlan(리플랜)
- 서비스 유형: 웹
- 서비스 URL: https://replan-coral.vercel.app
- 선택 지정과제: 지정과제 1번
- 서비스 타깃: 여행 중 날씨 변화, 관광지 혼잡, 동선 변경으로 빠른 대안이 필요한 자유여행객
- 서비스 개요: 한국관광공사 관광정보 OpenAPI와 날씨 데이터를 활용해 여행 중 발생한 날씨·혼잡·동선 변화를 반영하고, 현재 여행 지역에 맞는 대체 관광지와 이동 거리를 줄인 재설계 일정을 제공하는 웹 서비스

## 서비스 테스트 정보

- 로그인 방식: 로그인 불필요
- 권장 테스트 환경: 최신 Chrome 또는 Safari, PC·모바일 브라우저
- 별도 테스트 계정: 없음

## 심사위원 권장 테스트 시나리오

1. 지역을 `서울 종로구`, 스타일을 `문화·역사`로 선택하고 `이 조건으로 여행 시작하기`를 누른다.
2. 추천 카드 3개 이상에서 `일정에 담기`를 누른다.
3. `선택 장소로 일정 만들기`를 눌러 첫 장소 이후의 방문지가 가까운 순서로 재배치되는지 확인한다.
4. 채팅에 `경복궁이 너무 붐비고 비도 와. 조용한 실내 장소로 바꿔줘`를 입력한다.
5. 실내 문화시설 중 예상 혼잡 점수가 낮은 대안이 표시되는지 확인한다.

## 지정과제 연계 해시태그

- #실시간대안관광: 현재 지역 주변의 실제 관광 콘텐츠를 카드로 제시
- #복합상황재설계: 사용자 제보를 우선 반영해 날씨·혼잡 문제를 함께 처리
- #관광데이터추천: TourAPI `locationBasedList2`의 실시간 조회 결과 활용
- #이동동선최적화: 첫 장소를 유지하고 이후 장소를 좌표상 가까운 순서로 재배치

## 한국관광공사 OpenAPI 활용 정보

- 선택할 API명: 한국관광공사 국문 관광정보 서비스
- 실제 활용 오퍼레이션: `locationBasedList2`
- 활용 내용: 선택 지역 중심 좌표와 여행 스타일을 바탕으로 주변 관광지·문화시설·음식점·레포츠 정보를 실시간 조회하고 대체 장소 카드로 제공
- 보유 엔드포인트: `detailCommon2` 연동 API가 구현되어 있으나, 현재 사용자 핵심 흐름에서는 목록 조회를 중심으로 활용
- 데이터 출처 표기: `출처: ⓒ한국관광공사`

## 기타 API 활용 정보

- 데이터명: Open-Meteo Forecast API
- 활용 내용: 선택 지역 중심 좌표의 현재 날씨를 참고 정보로 조회
- 주의사항: 사용자가 직접 알린 현장 날씨와 관측값이 다를 경우 사용자 입력을 우선 반영

## 제출 직전 별도 준비 항목

- 공공데이터포털 인증키의 인코딩 키와 디코딩 키
- 대표 API 운영계정 신청 여부
- API 신청자명
- 최종 팀원 정보
- 지정 양식으로 작성한 10MB 이하 기능설명서 PDF

> 인증키는 저장소, 기능설명서, 화면 캡처에 노출하지 않는다. 접수 사이트의 지정된 인증키 입력란에만 입력한다.
